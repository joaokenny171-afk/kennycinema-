CINEPLAY - SISTEMA DE LOCAÇÃO DE FILMES

Tecnologias:
- HTML5
- CSS3
- JavaScript
- LocalStorage do navegador

Páginas:
- index.html: página inicial
- filmes.html: cadastro e gerenciamento de filmes
- clientes.html: cadastro e gerenciamento de clientes
- locacoes.html: registro e finalização de locações
- contato.html: formulário de contato

Classes JavaScript:
- Filme
- Cliente
- Locacao
- Contato

Como executar:
1. Extraia o ZIP.
2. Abra a pasta no VS Code.
3. Abra index.html no navegador.
4. Para uma execução melhor, você pode usar a extensão Live Server do VS Code.
5. Os dados ficam salvos no navegador usando LocalStorage.

Observação:
Este projeto é um sistema front-end para estudo. Não utiliza Python nem banco de dados.
